Privacy Policy

Last updated: [DATE] — Effective for: [BOT NAME] and its web dashboard

1. Who we are

[BOT NAME] ("the Bot", "we", "us") is a Discord application operated by [YOUR NAME / COMPANY NAME], contactable at [CONTACT EMAIL]. This policy covers the Bot and its web dashboard at [DASHBOARD URL].

2. What we collect

To operate, the Bot and dashboard store:

  • Server (guild) configuration — channel IDs, role IDs, and messages you set up for welcome/goodbye/logging/anti-spam/auto-escalation features.
  • Moderation records — warnings, bans, kicks, mutes, and similar actions taken through the Bot, including the Discord user IDs and usernames of the member and moderator involved, the reason given, and a timestamp. This exists to give your server a persistent audit trail.
  • Message content, only when a moderator acts on it — e.g. the content of a message flagged by anti-spam, or shown in edit/delete logs if you've enabled that feature. We do not log ordinary message content that isn't relevant to moderation.
  • Dashboard login sessions — if you use the web dashboard, we store your Discord user ID, username, avatar URL, and a Discord OAuth2 access/refresh token (used only to check which servers you can manage), plus a session identifier stored in your browser as a cookie.

We do not collect payment information, precise location, or data unrelated to running the Bot's features.

3. How we use it

Solely to provide the Bot's and dashboard's features: applying your configured settings, maintaining moderation history, and authenticating dashboard logins. We do not sell data, and we do not use it for advertising.

4. Where it's stored

Data is stored in a database operated by us at [HOSTING PROVIDER / LOCATION]. [Add detail here if you use a third-party host, e.g. "on servers provided by Railway/Render/a VPS provider located in [region]".]

5. How long we keep it

Guild configuration and dashboard sessions are deleted when the Bot is removed from a server (sessions also expire automatically after 7 days of inactivity). Moderation history (warnings, case log) is retained after the Bot is removed so it's available if the Bot is re-added later — server admins can request deletion of this history by contacting [CONTACT EMAIL].

6. Third parties

We share data with Discord only as required for the Bot/dashboard to function (this is inherent to any Discord bot). We do not share data with any other third party. [Update this section if you add analytics, error tracking like Sentry, or other third-party services.]

7. Your rights
